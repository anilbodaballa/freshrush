# ⚡ FreshRush Client

The frontend web application for **FreshRush**, built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features
- **Storefront**: Browse products, view flash deals, filter by categories, and manage shopping cart.
- **Checkout & Payments**: Integrated with Stripe for seamless credit/debit card transactions.
- **Live Order Tracking**: Interactive Leaflet maps showing real-time delivery rider movement.
- **Admin Panel**: Manage catalog items, fulfill orders, and assign riders.
- **Delivery Dashboard**: Live partner interface for managing assigned drop-offs with OTP verification.

## Scripts
- `npm run dev`: Launch development server on `http://localhost:5173`.
- `npm run build`: Compile TypeScript and bundle with Vite.
- `npm run preview`: Preview production build locally.
